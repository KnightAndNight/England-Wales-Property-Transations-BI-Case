# England & Wales Property Transactions Analysis BI Case
A Power BI portfolio project analysing property transactions in England and Wales in 2024 and 2025.

## Tools and Methods

- Power BI
- Power Query for combining and cleaning the 2024 and 2025 yearly files
- DAX measures and calculated columns
- Interactive filtering, drill-down geographical hierarchy, conditional formatting, and tooltip analysis

## Dashboard Pages

- **Market Overview** – key market indicators, price bands, and monthly trends
- **Location Analysis** – geographical distribution and county-level comparisons
- **Property Analysis** – transaction volume, price, build status, and tenure by property type
- **Year-on-Year Analysis** – comparison of transaction volume and median price between 2024 and 2025
- **County Market Momentum** – county-level changes in transaction volume and median price
